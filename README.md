# AirCard Resources

A community-curated collection of AirCard resources, Windows releases, Apple Wallet card skins, passcode themes, design tools, tutorials, and troubleshooting guides.

## Official & Community Resources

- [AirCardGuide](https://aircardguide.com/): Guides, tutorials, and community resources.
- [AirCard Skin Designer](https://aircardguide.com/designer): Create and customize card artwork.
- [AirCard Windows Releases](https://github.com/Lumid-Off/AirCard-Windows/releases): Download Windows builds and review release notes.
- [AirCard macOS Source & Issues](https://github.com/Mak5er/AirCard): Original project source.
- [AirCard Issues](https://github.com/Mak5er/AirCard/issues): Report bugs and review compatibility discussions.

## Skins & Themes

- **Apple Wallet Card Skins:** Custom artwork for supported Wallet cards.
- **Passcode Themes:** Explore compatible `.passthm` themes for supported iOS versions.
- **Custom Designs:** Use the [AirCard Designer](https://aircardguide.com/designer) to prepare artwork.

## Getting Started

1. Visit [AirCardGuide](https://aircardguide.com/) for guides and setup information.
2. Download the appropriate build from [AirCard Windows Releases](https://github.com/Lumid-Off/AirCard-Windows/releases).
3. Explore skins and prepare custom artwork with the [Designer](https://aircardguide.com/designer).
4. Check the upstream [GitHub Issues](https://github.com/Mak5er/AirCard/issues) if you encounter problems.

## Disclaimer

This is an independent community resource collection and is not an official Apple project. AirCardGuide is independent of the upstream software maintainers. Compatibility and available features may vary by software release and iOS version. Always review the original repository, license, and release notes before using or redistributing software or themes.
